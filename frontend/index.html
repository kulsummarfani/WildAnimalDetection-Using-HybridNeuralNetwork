#About VanRakshak AI

A Hybrid Deep Learning System For Village Boundary Safety

Boundary cameras feed a YOLOv8 detector and a Bi-LSTM behaviour model that together spot wild animals approaching a village and judge whether they're moving toward it. When they are, the system fires a dual-tier alert — a detailed feed for the watchman, a simple safety message for residents — before the animal reaches the boundary.

#What The System Does

Core Capabilities Of VanRakshak AI

Panchayat emergency line

+012 345 6789

Real-Time Detection
YOLOv8 scans the boundary camera feed frame by frame to spot animals as they appear.
Species Classification
Every detection is classified into a known species — Cheetah, Jaguar, Leopard, Lion or Tiger.
Behaviour Analysis
A Bi-LSTM layer reads short frame sequences to judge if the animal is approaching or moving away.
Distance Estimation
A simplified boundary-reference calculation estimates how far the animal is from the village edge.
Watchman Alerts
Detailed alerts with species, confidence score, distance and a clip go to the surveillance dashboard.
Resident Alerts
Residents in the affected zone get a plain-language safety message — no jargon, no clutter.
Alert History
Every alert is logged with a timestamp so patterns in animal activity can be reviewed later.
Operator Feedback
Watchmen can flag false positives, building a feedback set for future model retraining.
